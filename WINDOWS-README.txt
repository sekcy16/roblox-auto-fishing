Roblox Auto Fishing — เวอร์ชัน 0.0.6 (Windows)

โหมดการทำงานบน Windows:
- รองรับเฉพาะ "โหมดปกติ (จอเดียว)" เท่านั้น
- ข้อกำหนด: ต้องเปิดหน้าต่าง Roblox ค้างไว้ด้านหน้าตลอดเวลาที่ทำงาน และบอทจะควบคุมเมาส์ร่วมกับผู้ใช้
- คำเตือน: รุ่นปัจจุบันยังไม่รองรับโหมดสองจอ (ไม่มีการเปิดใช้ Gamescope, Sober หรือการส่ง input เบื้องหลัง)

วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP ก่อนใช้งาน
2. ดับเบิลคลิก RobloxAutoFishing-v0.0.6.exe
3. เลือกหน้าต่าง Roblox และตั้งพื้นที่ตรวจจับตามลำดับในโปรแกรม
4. กด F8 เมื่อต้องการหยุดทันที

โปรแกรมจะเก็บ settings.json และ bite-template.png ไว้ที่:
%LOCALAPPDATA%\RobloxAutoFishing

เพื่อนแต่ละคนต้องเลือกพื้นที่และสร้างภาพตัวอย่างสัญญาณปลากินใหม่ เพราะขนาดจอและตำแหน่งเกมอาจต่างกัน

หาก Windows แสดงคำเตือน SmartScreen ให้ตรวจสอบว่าได้รับไฟล์จากผู้ส่งที่เชื่อถือได้ก่อนเปิด โปรแกรมรุ่นนี้ยังไม่ได้เซ็นด้วยใบรับรองดิจิทัล
