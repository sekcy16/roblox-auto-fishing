Roblox Auto Fishing — เวอร์ชัน 0.0.8 (Windows)

โหมดการทำงานบน Windows:
- โหมดปกติ (จอเดียว - แนะนำ): ควบคุมเมาส์ผ่าน Win32 SendInput โดยตรง มีระบบ State Reconciliation คืนสถานะเมาส์และลองส่งใหม่อัตโนมัติ พร้อมระบบตรวจจับ UIPI สิทธิ์ Administrator
- โหมดสองจอ (ทดลอง): ส่งการคลิกตรงเข้าหน้าต่าง Roblox บนจอ 2 ผ่าน Win32 PostMessage เพื่อไม่ให้แย่งเมาส์และโฟกัสบนจอ 1 (อยู่ระหว่างการทดสอบพิสูจน์การตอบสนองจริงในเกม)

เครื่องมือทดสอบและวินิจฉัยบน Windows:
- ปุ่ม "⚡ ทดลองกดค้าง" ในหน้าจอตั้งค่า: มีเวลานับถอยหลัง 3 วินาทีให้สลับไปเกม และเลือกระยะเวลาได้ (0.5s, 1.0s, 2.0s) เพื่อยืนยันว่า Windows และ Roblox ตอบสนองต่อคำสั่งเมาส์จริง
- ปุ่ม "📋 คัดลอกผลวินิจฉัย (Diagnostics)" และ "📂 เปิดโฟลเดอร์ Log": คัดลอกข้อมูล telemetry, PID, HWND, สถานะ controller, และบันทึก debug.log สำหรับการแก้ไขปัญหา
- สคริปต์ทดสอบ: รันคำสั่ง `python scripts/test_windows_input.py` เพื่อทดสอบการส่ง PostMessage ในโหมดสองจอ

วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP ก่อนใช้งาน
2. ดับเบิลคลิก RobloxAutoFishing-v0.0.8.exe (หาก Roblox รันแบบสิทธิ์ Administrator ต้องรันโปรแกรมนี้ในฐานะ Run as Administrator ด้วยเช่นกัน)
3. เลือกหน้าต่าง Roblox และตั้งพื้นที่ตรวจจับตามลำดับในโปรแกรม
4. กด F8 เพื่อเริ่มหรือหยุดการทำงานได้ทันที (ใช้ได้จากทุกหน้าต่าง)

โปรแกรมจะเก็บ settings.json, bite-template.png และ debug.log ไว้ที่:
%LOCALAPPDATA%\RobloxAutoFishing

เพื่อนแต่ละคนต้องเลือกพื้นที่และสร้างภาพตัวอย่างสัญญาณปลากินใหม่ เพราะขนาดจอและตำแหน่งเกมอาจต่างกัน

หาก Windows แสดงคำเตือน SmartScreen ให้ตรวจสอบว่าได้รับไฟล์จากผู้ส่งที่เชื่อถือได้ก่อนเปิด โปรแกรมรุ่นนี้ยังไม่ได้เซ็นด้วยใบรับรองดิจิทัล
